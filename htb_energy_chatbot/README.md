# HTBエナジー ホームページ常駐型AIチャットボット

##  概要

HTBエナジーのホームページ上に常駐するAIチャットボットです。  
顧客とのやり取りを記録・評価し、すべてのログをkintoneに保存します。

URL: https://storage.googleapis.com/latest_chatbot/index.html

---

##  使用ツール

- **Dify**  
  顧客からの質問に対して、自然言語で回答を生成するバックエンドAI。

- **kintone**  
  ・全チャットのログ（質問・回答）を保存  
  ・顧客からの評価も記録し、紐づけて管理

---

##  実行フロー

1. **顧客が質問を送信**  
   - フロントエンドからの入力を受け取る

2. **Difyに問い合わせ**  
   - 質問をDify APIに送信  
   - 応答メッセージと一緒に **メッセージID** を受け取る

3. **UIとkintoneへの同時送信**  
   - Difyからの返答をチャットUIに表示  
   - 同時に、質問・回答ペアとメッセージIDを **kintoneに保存**

4. **評価の受付と反映**  
   - 顧客が返答に対して評価（Good/Bad）を送信した場合  
   - メッセージIDをキーに、評価を該当記録に上書き保存

---

##  保存される情報（kintone）

| 項目         | 説明                            |
|--------------|---------------------------------|
| メッセージID | 質問と回答の一意キー            |
| 質問内容     | 顧客が送った入力メッセージ      |
| 回答内容     | Difyからの応答                  |
| タイムスタンプ | やり取りが発生した日時         |
| 評価（任意） | 顧客によるGood/Bad評価         |
